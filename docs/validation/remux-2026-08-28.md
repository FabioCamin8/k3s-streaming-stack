### Backup boundary and security

`/data` is mounted from the `remux-data` local-path PVC. The K3s datastore
backup procedure captures K3s server state under
`/var/lib/rancher/k3s/server/db` and related control-plane credentials; it does
not capture local-path PVC files. Therefore the Kubernetes backup is **not** an
off-node Remux application backup. Off-node PVC backup/restore remains a future
operational milestone.

The previously observed shell-history credential was not reproduced or used.
Rotation was not performed by this execution because the value and its owning
control plane require operator action; the live cluster access used the
independent authorized SSH/QEMU Guest Agent path. Treat rotation as a separate
security action if the credential remains valid.

WAN streaming forwarding remains intentionally disabled. Infuse and Swiftfin
were not available for a physical client test: Infuse **NOT TESTED** and
Swiftfin **NOT TESTED**. No client PASS, external-provider playback PASS, or
full Jellyfin compatibility claim is made.
